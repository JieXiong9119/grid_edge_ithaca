# Simulation artifacts

The five existing ResStock model trees retain their original folder names. Original downloaded models feed matching; rebuilt baseline, upgrade-04 control and upgrade-04 demand-flex models feed scenario comparison.

These local, git-ignored trees contain expensive-to-regenerate inputs, schedules, workflows and simulation outputs. Do not delete or mix releases. Archive with provenance before regeneration. Notebooks 1 and 2 write here; notebooks 3 and 5 read here. See [../docs/repository_structure.md](../docs/repository_structure.md#model-folders-and-scenario-tags).

Saved artifacts contain historical absolute paths. Local Windows junctions under the compatibility directory preserve these references; do not remove those links until the affected workflows have been regenerated and reviewed.
